# Agent instructions

- **Before product, design or eval work,** read `design/research/CONTEXT.md` (what we
  know about users) and `design/eval-product-redesign.md` (decisions so far).
- **Research findings go into `design/research/CONTEXT.md`;** design decisions go into
  the decision log in `design/eval-product-redesign.md`. One commit per decision, so
  git history shows how the design evolved.
- **Personal health data never enters git:** `journals/`, `exports/`, `raw/` and
  `*.duckdb` stay ignored. Strip usernames from any research quotes.
